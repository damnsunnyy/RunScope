How to read this page

RunScope reads public workflow and run history through the GitHub REST API. It requests no write access and stores nothing on a server. Data reflects the latest 100 runs returned by GitHub; the selected time window can only show runs in that set. Success rate excludes cancelled, skipped, and in-progress runs. Median duration uses each completed run's start and update times.
